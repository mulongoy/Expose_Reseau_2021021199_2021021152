# APPLICATION MOBILE DE PLANIFICATION ET DE SUIVI DE MAINTENANCE DU PARC INFORMATIQUE

## Présentation du projet

Cette application mobile permet de planifier, gérer et suivre les opérations de maintenance d'un parc informatique.

Elle a été réalisée avec React Native et Expo dans le cadre du cours de Langage de Programmation Mobile, en BAC4 SI, année académique 2026-2027.

## Objectifs du projet

- Faciliter la gestion des équipements informatiques.
- Assurer le suivi des techniciens.
- Planifier les opérations de maintenance.
- Enregistrer et suivre les interventions.
- Faciliter le diagnostic et la surveillance des équipements.

## Fonctionnalités de l'application

1. **Accueil :** tableau de bord présentant les informations principales.
2. **Équipements :** ajout, consultation, modification et suppression des équipements.
3. **Techniciens :** gestion des techniciens.
4. **Planning :** planification et suivi des maintenances.
5. **Interventions :** enregistrement et suivi des interventions.
6. **Diagnostic :** vérification de la connectivité réseau et Internet.
7. **Localisation :** géolocalisation et affichage des équipements sur une carte.
8. **Caméra :** prise de photos pour les audits des équipements.
9. **Audio :** enregistrement de mémos vocaux.
10. **Contacts :** consultation des contacts du téléphone.
11. **Notifications :** rappels de maintenance.

## Installation et exécution

### 1. Cloner le dépôt

```bash
git clone https://github.com/mulongoy/Expose_Reseau_2021021199_2021021152.git
```

### 2. Accéder au dossier

```bash
cd Expose_Reseau_2021021199_2021021152
```

### 3. Installer les dépendances

```bash
npm install
```

### 4. Démarrer l'application

```bash
npx expo start
```

## Organisation du projet

- `src/app/` : écrans et navigation.
- `src/components/` : composants de l'application.
- `src/database/` : gestion de la base de données.
- `app.json` : configuration Expo.
- `eas.json` : configuration de compilation Android.
